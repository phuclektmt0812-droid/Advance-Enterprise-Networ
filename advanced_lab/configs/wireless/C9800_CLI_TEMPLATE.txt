TVI CATALYST 9800 — WLAN / AAA / POLICY PROFILE / POLICY TAG
================================================================

Reference platform: Catalyst 9800 IOS XE. This template follows the
controller object model: WLAN profile defines SSID/security, policy profile
defines client VLAN/policy, and policy tag maps WLAN to policy profile.
Confirm the exact command support on the controller release before applying.

PLACEHOLDERS — REPLACE BEFORE APPLYING
--------------------------------------
<RADIUS_IP>                 RADIUS server address
<RADIUS_SHARED_SECRET>      secret supplied outside source control
<AP_ETHERNET_MAC>           joined AP Ethernet MAC
<ADMIN_SOURCE_SUBNET>       permitted management subnet

VLAN DESIGN
-----------
TVI-CORP WLAN ID 110 -> TVI-CORP-POLICY -> VLAN 110
TVI-GUEST WLAN ID 150 -> TVI-GUEST-POLICY -> VLAN 150

PRE-CHECKS
----------
- VLAN 110 and 150 exist end-to-end on the switching path.
- WLC management and AP CAPWAP reachability are configured.
- RADIUS server is reachable from the WLC and has the WLC as a client.
- RADIUS shared secret is entered interactively; never commit it here.
- Guest web-auth/portal dependencies are available before enabling guest SSID.
- Keep console/management rollback access and do not expose WLC management on WAN.

AAA / RADIUS BASELINE
---------------------
aaa new-model
radius server TVI-RADIUS
 address ipv4 <RADIUS_IP> auth-port 1812 acct-port 1813
 key 0 <RADIUS_SHARED_SECRET>
aaa group server radius TVI-RADIUS-GROUP
 server name TVI-RADIUS
aaa authentication dot1x TVI-DOT1X group TVI-RADIUS-GROUP
aaa authorization network TVI-NETWORK group TVI-RADIUS-GROUP

CORPORATE WLAN — WPA2-ENTERPRISE / 802.1X
-----------------------------------------
wlan TVI-CORP 110 TVI-CORP
 security dot1x authentication-list TVI-DOT1X
 security wpa wpa2
 security wpa wpa2 ciphers aes
 no shutdown

GUEST WLAN — WEB AUTHENTICATION
-------------------------------
! Configure the selected local/external web-auth authentication list and
! parameter map before enabling this WLAN. Do not deploy an open guest SSID.
wlan TVI-GUEST 150 TVI-GUEST
 security web-auth
 security web-auth authentication-list default
 security web-auth parameter-map global
 no shutdown

POLICY PROFILES AND TAG
-----------------------
wireless profile policy TVI-CORP-POLICY
 vlan 110
 no shutdown
wireless profile policy TVI-GUEST-POLICY
 vlan 150
 no shutdown
wireless tag policy TVI-SITE-POLICY
 wlan TVI-CORP policy TVI-CORP-POLICY
 wlan TVI-GUEST policy TVI-GUEST-POLICY

AP ASSIGNMENT
-------------
ap <AP_ETHERNET_MAC>
 policy-tag TVI-SITE-POLICY
end
write memory

VALIDATION
----------
show wlan summary
show wireless tag policy detailed TVI-SITE-POLICY
show wireless profile policy detailed TVI-CORP-POLICY
show wireless profile policy detailed TVI-GUEST-POLICY
show ap summary
show wireless client summary
show wireless stats ap join
show aaa servers

Acceptance:
- AP joins the controller and CAPWAP is established.
- Corporate clients authenticate via RADIUS and receive VLAN 110 addressing.
- Guest clients complete the configured web-auth flow and receive VLAN 150.
- Guest clients cannot reach corporate, management, IoT or other private ranges.
- RADIUS failure and WLC/AP restart recovery are tested.

The WLAN-to-policy-profile mapping and policy-tag workflow are documented by
Cisco. Guest web-auth commands and AAA behavior vary by IOS XE release; verify
the chosen authentication method and parameter map on the target controller.
